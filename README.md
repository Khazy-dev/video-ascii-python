# video-ascii-python
Convierte y reproduce un video en estilo ASCII directamente en la terminal usando Python y OpenCV.

## Vista general

Este proyecto toma un video, convierte cada frame a escala de grises, lo redimensiona y reemplaza cada píxel por un carácter ASCII según su intensidad. El resultado es una animación tipo arte ASCII dentro de la consola.

## Características

- Reproduce video en la terminal
- Convierte frames a caracteres ASCII
- Ajusta el tamaño al espacio disponible en la consola
- Mantiene un ancho fijo para evitar saltos o deformaciones
- Sin interfaces gráficas, todo funciona desde terminal

## Requisitos

Antes de ejecutar el proyecto necesitas tener instalado:

- Python 3.8 o superior
- pip
- OpenCV

## Instalación
Deber instalar opencv, desde la terminal puedes colocar.
pip install opencv-python.
Clona el repositorio o descarga los archivos. 

El video a convertir debe estar en el mismo archivo donde se encuentra video-ascii.
